# Development

## Commands

| Task | Command |
|------|---------|
| Dev server | `npm run dev` |
| Production build | `npm run build` |
| Typecheck | `npx tsc --noEmit` (run `npx next typegen` first if `.next` was deleted) |
| Lint | `npm run lint` |
| Format schema | `npx prisma format` |
| Migrate | `npx prisma migrate dev --name <name>` |
| Seed | `npm run db:seed` |
| DB studio | `npx prisma studio` |

Verification loop after changes: `npx tsc --noEmit` → `npm run lint` → `npm run build`. A fresh `.next` also removes the global `PageProps`/`LayoutProps`/`RouteContext` helpers that `next dev`/`next build` regenerate — run `npx next typegen` to recreate them.

## Conventions

- **Modules** live under `src/app/(app)/<module>/`; each module has its own `actions.ts` with `"use server"` and `requireModule(level)` guards (see [architecture.md](architecture.md)).
- **Labels & status maps** live in `src/lib/<module>-labels.tsx` (arrays of `{ value, label, color }` plus a `MAP`). `Badge` is re-exported from `src/lib/crm-labels.tsx`.
- **Mutations** go through server actions invoked from plain HTML forms. Add an `ActivityLog` row for key mutations; call `revalidatePath` after writes.
- **Helpers** are pure functions in `src/lib/` (`finance-helpers.ts`, `project-progress.ts`, `team-workload.ts`, `format.ts`).
- **Currency** is AED only (single-company, single-currency). `format.ts` formats AED + en-GB dates.
- **Client components** go in `src/components/<module>/`; shared UI primitives in `src/components/ui/`.

## Platform gotchas (Windows)

- Use `npm.cmd`/`npx.cmd` in PowerShell and any script that pipes output — the bare `npm`/`npx` (`.ps1`) breaks pipelines. On some machines an empty `C:\Windows\System32\npm` file shadows the real `npm.cmd`; work around it by calling `npm.cmd` directly.
- Google Fonts are blocked on some networks — this project uses `next/font` with Geist (bundled), so no external font fetch is required.

## Next.js 16 gotchas (verified on this machine)

- `middleware` is **`src/proxy.ts`** in Next 16.
- `PageProps`/`LayoutProps`/`RouteContext` are global helpers generated by `next dev`/`next build`/`next typegen` — deleting `.next` removes them.
- Any component using `useSearchParams` needs a `<Suspense>` boundary.
- `(app)/layout.tsx` exports `dynamic = "force-dynamic"` so DB pages are not prerendered — keep it.

## shadcn / Base UI gotchas

- Base UI components take a `render={<Component/>}` prop, **not** `asChild`.
- Base UI `Select` submits its value natively via the `name` prop on `Select.Root`.
- `Button` defaults `nativeButton` to `true`. When rendering a non-`<button>` element (e.g. `ButtonLink` renders a `<Link>`), pass `nativeButton={false}` — otherwise Base UI logs a console warning and you lose button semantics.
- When shadcn says "use asChild" in its docs, use the `render` prop instead.

## Adding a feature (checklist)

1. If it changes data: edit `prisma/schema.prisma`, run `npx prisma format` + `npx prisma migrate dev --name <name>` + `npx prisma generate`.
2. Add labels to the module's `<module>-labels.tsx` if there are new statuses.
3. Add the page under `src/app/(app)/<module>/...` (server component; query with `db`; guard with `requireModule`).
4. Add actions to the module's `actions.ts` (zod schema → write → activity log → revalidate/redirect).
5. Add reusable client bits under `src/components/<module>/`.
6. Wire navigation into `src/components/layout/<module>-nav.tsx` / `nav-items.tsx`.
7. Update this docs set and `AGENTS.md` if behavior/commands changed.
8. Verify: typecheck → lint → build → manual test.

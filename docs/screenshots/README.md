# Screenshots

Planned screenshots for the documentation. Each doc page references its captures via markdown images pointing here (e.g. `![Caption](screenshots/dashboard.png)`).

## Naming convention

- All lowercase, hyphenated, per page: `dashboard.png`, `crm-leads.png`, `finance-invoices.png`, etc.
- One file per captured view. If a view has variants, suffix them: `projects-board.png`, `projects-board-empty.png`.

## Adding a real screenshot

1. Log in and navigate to the page.
2. Capture the full viewport (PNG recommended).
3. Save it into `docs/screenshots/` with the exact name referenced in the doc.
4. Add a one-line caption under the image in the corresponding doc (a `> **Placeholder.**` block already marks the spot — replace it with the caption).
